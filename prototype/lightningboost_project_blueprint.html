Tech Stack
The core idea: your low-RAM laptop stays lightweight. Heavy AI tasks are detected and routed to AMD cloud GPUs via ROCm + HuggingFace, then results stream back locally.
1
Local monitor MVP
Days 1–2
Build the foundation: a Streamlit dashboard that reads RAM, CPU, and process data from psutil. Flask serves the data as a REST API. This is the first thing you demo.
psutil integration Flask /metrics endpoint Streamlit live dashboard RAM % gauge Process list
2
AI optimizer (LangChain + HuggingFace)
Days 2–3
Add smart recommendations using LangChain chained to a HuggingFace model. When RAM is low, the AI suggests what to close, what to defer, and how to reclaim memory without user guesswork.
LangChain chain setup HuggingFace model API Prompt engineering Tip display in UI Threshold triggers
3
AMD cloud offload
Days 3–5
The core AMD hackathon integration. Heavy tasks detected locally are serialized and sent to an AMD Developer Cloud GPU instance running a ROCm-accelerated Docker container. HuggingFace TGI (text-generation-inference) handles model serving with ROCm backend.
AMD Dev Cloud setup ROCm Docker container HuggingFace TGI (rocm) Task serializer Result streaming Offload trigger logic
4
Polish + demo prep
Days 5–7
UI polish, error handling, demo script, and a technical walkthrough writeup (required for AMD Build in Public prize track). Record a short demo video showing the full local → cloud → result loop.
UI polish Error handling Demo video GitHub README Technical blog post Open source
